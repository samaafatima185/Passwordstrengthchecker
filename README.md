# Passwordstrengthchecker
A simple python-based begginer cybersecurity project that evaluates the strength of a password based on common validation rules .
#Project Overview
So basically this project checks whether a password is weak ,medium or storng by analyzing different password characteristics.
#Features
Checks password length
Detect uppercase letter 
Detect lowercase letter 
Detect numbers
Detect symbols
Classified password as:
.weak
.medium
.strong
#Technology
simple python languge is used .
#Working
The program start working and checks 
.password has sufficient lenth or not 
.it contains an uppercase ,lowercase letters or not
.it contains a number or not 
.it contain symbol , emojy or not 
Based on these constraints ,the program checks and then display the password strength.
